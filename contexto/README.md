# Contexto del Proyecto

Estos archivos son la memoria editable que Claude Code carga para entender el objetivo del workspace antes de implementar.

## Orden recomendado

1. `info-negocio.md` — qué hace la organización o producto.
2. `info-personal.md` — tu rol, responsabilidades y preferencias de trabajo.
3. `estrategia.md` — prioridades actuales y criterios de decisión.
4. `proyectos.md` — iniciativas activas, completadas y backlog.
5. `datos-actuales.md` — métricas, links y estado operativo reciente.

## Regla práctica

Mantené cada archivo corto y accionable. Si una frase no ayuda a decidir, priorizar o verificar trabajo, probablemente no pertenece al contexto inicial.

## Checklist antes de iniciar una sesión

- [ ] La prioridad actual aparece en `estrategia.md` o `proyectos.md`.
- [ ] Los datos sensibles están fuera del repo y documentados como variables de entorno.
- [ ] Los proyectos completados tienen ubicación o link de referencia.
- [ ] Los criterios de éxito están escritos como resultados verificables.
