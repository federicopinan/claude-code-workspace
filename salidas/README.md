# Salidas

Entregables, reportes y análisis generados durante el desarrollo.

## Contenido

- Reportes de análisis (de `sdd-verify`)
- Métricas de cobertura de tests
- Reportes de deuda técnica
- Documentación de decisiones arquitectónicas

## Formato

Los archivos se nombran con fecha y descripción:

```
salidas/
├── 2026-05-18-analisis-seguridad.md
├── 2026-05-18-reporte-cobertura.md
└── metricas-proyecto.json
```
