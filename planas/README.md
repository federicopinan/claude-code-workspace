# Planas

Planes de implementación creados con `/crear-plan` o durante el workflow SDD.

## Uso

Los planes se crean automáticamente cuando usás:

- `/crear-plan [descripción]` — Crear plan manualmente
- `/sdd-ff [nombre]` — Fast-forward SDD que genera plan

## Estructura de un plan

```
planes/
├── 2026-05-18-mi-feature.md
└── 2026-05-19-otra-feature.md
```

Los planes incluyen:
- Objetivos y alcance
- Pasos específicos
- Archivos a modificar
- Tiempo estimado
- Verificaciones necesarias
